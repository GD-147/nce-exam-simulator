# NCE Exam Simulator

Independent practice portal for NCE specifications effective July 1, 2027.
170 questions / 225 minutes / 140 scored + 30 unscored / A-B-C.
Six behavioral domains. Practice blocks of 30 questions.

No practice exams or PDFs have been uploaded yet. Only add existing, validated files
under packs/nce/data/ and packs/nce/pdf/, then list them in config.json.

This is an independent educational product; it is not affiliated with, sponsored,
endorsed, or approved by NBCC. Practice items are original, not real NCE questions.

The access code is a convenience gate, not a secure authentication system.
